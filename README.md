# 할 일 (TODO)

빌드 도구도, 패키지 설치도 필요 없는 단일 페이지 할 일 관리 앱입니다.
HTML · CSS · 바닐라 JavaScript로만 만들어졌고, 데이터는 브라우저의 `localStorage`에 저장됩니다.

## 실행

`index.html`을 브라우저로 열면 끝입니다.

```bash
start index.html
```

로컬 서버로 띄우고 싶다면:

```bash
npx serve .
```

## 기능

| 분류 | 내용 |
| --- | --- |
| 기본 | 추가 · 완료 토글 · 편집 · 삭제 |
| 속성 | 우선순위(높음/보통/낮음), 마감일 |
| 보기 | 전체 / 진행 중 / 완료 필터, 검색, 정렬(직접·마감일·우선순위·최신) |
| 정렬 | 드래그 앤 드롭, 키보드(`Alt` + `↑`/`↓`) |
| 일괄 | 전체 완료 토글, 완료 항목 일괄 삭제 |
| 안전장치 | 삭제 후 **실행 취소** (7초) |
| 데이터 | JSON 내보내기 / 가져오기(병합) |
| 화면 | 밝은·어두운·시스템 테마, 진행률 바, 모바일 대응 |
| 접근성 | 키보드 전용 조작, `aria-live` 안내, 포커스 유지 |

마감일은 상대 표기(`오늘`, `내일`, `3일 뒤`, `2일 지남`)로 보여주고, 기한이 지난 항목은 빨간색으로 강조됩니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `N` | 새 할 일 입력창으로 이동 |
| `/` | 검색창으로 이동 |
| `1` `2` `3` | 전체 / 진행 중 / 완료 필터 |
| `Enter` | 추가, 편집 저장 |
| `Esc` | 편집 취소, 검색어 지우기 |
| `Alt` + `↑` `↓` | 항목 순서 이동 (직접 정렬일 때) |
| `?` | 단축키 도움말 |

## 파일 구조

```
index.html   마크업, SVG 아이콘 스프라이트, 항목 <template>
styles.css   디자인 토큰(CSS 변수) 기반 스타일 · 다크 모드 · 반응형
app.js       상태 관리, 저장소, 렌더링, 이벤트 (IIFE, 의존성 없음)
```

## 데이터

| 키 | 내용 |
| --- | --- |
| `todo.items.v1` | 할 일 배열 |
| `todo.prefs.v1` | 필터 · 정렬 · 테마 설정 |

항목 한 개의 형태:

```json
{
  "id": "im4k2x1a9f",
  "title": "장보기",
  "done": false,
  "priority": "normal",
  "due": "2026-08-20",
  "createdAt": 1755300000000,
  "completedAt": null
}
```

localStorage는 브라우저·기기별로 분리되어 있고 브라우저 데이터를 지우면 함께 사라집니다.
중요한 목록은 **내보내기**로 JSON 백업을 받아 두세요. 가져오기는 기존 목록을 지우지 않고 뒤에 덧붙입니다(ID 충돌 시 새 ID 부여).

읽어 들인 데이터는 항상 검증·정규화하므로, 손상된 저장값이 있어도 앱이 깨지지 않고 해당 항목만 버려집니다.
